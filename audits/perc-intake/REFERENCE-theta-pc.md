# Reference statement: θ(p_c) = 0 for bond percolation on ℤ^d, d ≥ 2

Written before reading `Challenge.lean` or any library statement file, from
the standard definitions (Grimmett, *Percolation*, 2nd ed., Springer 1999,
§1.1–1.4; Kozma–Nitzan, arXiv:2401.12397, the preprint
the artifact formalizes; see C1 for status). One clause per list item, so `STATEMENT.md`
can pair each with the Lean clause it matches. Only the headline's task
description (the README sentence quoted in the audit brief) was known when
this was written.

## Objects

- O1. **Lattice.** d ≥ 1 an integer; vertex set V = ℤ^d, i.e. d-tuples of
  integers. The origin 0 = (0,…,0).
- O2. **Edges.** The nearest-neighbour edge set E^d = { {x, y} : x, y ∈ ℤ^d,
  ‖x − y‖₁ = 1 }, i.e. x and y differ by ±1 in exactly one coordinate and
  agree in all others. Edges are UNORDERED (the graph is simple, undirected,
  no loops). E^d is countably infinite.
- O3. **Configurations.** Ω = {0,1}^{E^d} (equivalently the set of subsets of
  E^d: ω ↔ the set of open edges {e : ω(e) = 1}), with the product
  σ-algebra F generated by the cylinder events {ω : ω(e) = 1}.
- O4. **Measure.** For p ∈ [0,1], P_p = ⊗_{e ∈ E^d} Bernoulli(p): the unique
  probability measure on (Ω, F) under which the coordinates ω(e) are
  independent and each is 1 with probability p. Each EDGE carries one
  independent coin; in particular the two orientations (x,y) and (y,x) of an
  edge must NOT be independent coins (that would be a different model: a
  directed/oriented edge measure, with the undirected edge open with
  probability 2p − p² or p² depending on the convention).
- O5. **Open subgraph.** The random graph (ℤ^d, {e : ω(e) = 1}).
- O6. **Open cluster of the origin.** C(0) = C_ω(0) = the set of x ∈ ℤ^d
  joined to 0 by a finite path of open edges (0 ∈ C(0) always). This is a
  connectivity notion in the INFINITE graph; a version that only counts paths
  inside a finite box Λ_n changes the meaning unless n → ∞ is taken.
- O7. **"Infinite".** |C(0)| = ∞, i.e. C(0) is not a finite set of vertices.
  Equivalent formulations: for every n, 0 is joined by an open path to the
  boundary ∂Λ_n of the box Λ_n = [−n,n]^d (by local finiteness of ℤ^d,
  König); so {|C(0)| = ∞} = ⋂_n {0 ↔ ∂Λ_n} is a countable intersection of
  cylinder events and is F-measurable.
- O8. **Percolation probability.** θ(p) = P_p(|C(0)| = ∞), a function
  [0,1] → [0,1].
- O9. **Monotonicity (fact, not definition).** θ is non-decreasing in p
  (standard coupling: ω_p(e) = 1{U_e ≤ p} with U_e i.i.d. uniform), with
  θ(0) = 0 and θ(1) = 1.
- O10. **Critical probability.** Textbook: p_c(d) = sup{ p ∈ [0,1] : θ(p) = 0 }.
  The README form: p_c := inf( {p ∈ [0,1] : θ(p) > 0} ∪ {1} ).
  Equivalence given O9: let A = {p : θ(p) = 0} and B = {p ∈ [0,1] : θ(p) > 0}
  = [0,1] \ A. By monotonicity A is an initial segment of [0,1] (an interval
  [0,a] or [0,a)) and B the complementary final segment, so sup A = inf B
  whenever both are nonempty. A ∋ 0 is always nonempty. B could be empty only
  if θ ≡ 0 on [0,1], which is false since θ(1) = 1 — but a definition must
  not RELY on a fact it has not proved, so the ∪ {1} makes the inf form
  well-defined unconditionally: if B = ∅ then p_c = 1 = sup A. If B ≠ ∅ then
  inf(B ∪ {1}) = min(inf B, 1) = inf B since B ⊆ [0,1]. So the two forms
  agree for every monotone θ with θ(0) = 0, without needing θ(1) = 1.
  Without monotonicity they can differ, so a formal p_c in inf-form is the
  textbook p_c only via a monotonicity proof (or via p_c being used only
  through the conclusion θ(p_c) = 0, see C1).
- O11. **Non-triviality (fact, not definition).** For d ≥ 2,
  0 < p_c(d) < 1 (Peierls/Hammersley; Grimmett Thm 1.10), and p_c(2) = 1/2
  (Kesten 1980). For d = 1, p_c = 1 and θ(1) = 1, so the claim FAILS for
  d = 1: this is why d ≥ 2 is a genuine hypothesis.

## Hypotheses

- H1. d is an integer with d ≥ 2.
- (No hypothesis on p: p_c is a defined number, not a parameter.)

## Conclusion

- C1. θ(p_c(d)) = 0, i.e. P_{p_c}( |C(0)| = ∞ ) = 0: at the critical point
  there is almost surely no infinite open cluster containing the origin
  (equivalently, by ergodicity, no infinite open cluster at all). An
  EQUALITY at the single point p_c, not a limit statement
  lim_{p↓p_c} θ(p) = 0 (that is right-continuity at p_c, which with
  θ(p_c) = 0 and monotonicity is equivalent to continuity of θ at p_c from
  the left, and a different statement in general) and not an inequality
  θ(p_c) ≤ ε. Historical status: d = 2 Kesten/Harris; d ≥ 11 (Fitzner–van
  der Hofstad, lace expansion); the 2024 Kozma–Nitzan preprint claims it for
  all d ≥ 2 — the headline therefore formalizes a recent and, for
  3 ≤ d ≤ 10, previously open result.

## What would make a formal version weaker (or different)

Each is a check for `STATEMENT.md`:

- W1. Wrong graph: adjacency other than ‖x−y‖₁ = 1 (e.g. ℓ∞ / king's-move
  neighbours, directed edges, self-loops, a torus or box instead of ℤ^d, a
  vertex type that is not ℤ^d such as ℕ^d or Fin n^d).
- W2. Wrong configuration space or measure: a measure that is not the
  product Bernoulli(p) over UNORDERED edges (independent coins per ordered
  pair, per vertex = site percolation, a measure that is not a probability
  measure, the zero measure, a Dirac mass); p not clamped / undefined outside
  [0,1] where it matters.
- W3. Cluster through a finite box (only paths inside Λ_n) with no limit,
  or connectivity through ALL edges rather than open ones (cluster = ℤ^d,
  θ ≡ 1), or through no edges (cluster = {0}, θ ≡ 0).
- W4. "Infinite" meaning something else: e.g. unbounded in one coordinate
  only, or "contains infinitely many edges" when the vertex set is meant
  (equivalent here by local finiteness, but must be checked), or Set.Infinite
  of something trivially finite/infinite.
- W5. A θ that is trivially 0: the event empty, non-measurable in a way that
  makes the (outer) measure misbehave, or a probability taken in a measure
  under which it is 0 for all p (then the conclusion is vacuous).
- W6. A p_c that is trivially 1 (e.g. B written so it is always empty, then
  θ(1) = 0 would be FALSE for the honest θ, so this mostly shows up as
  inconsistency, not vacuity) or trivially 0 (e.g. inf over a set that
  contains 0 or a negative number, or `sInf` of a set not bounded below,
  which Mathlib sends to 0).
- W7. The conclusion as an inequality, a limit, an "eventually", or under an
  extra hypothesis (e.g. an assumed bound, a named open result as a premise).
- W8. A vacuous hypothesis (d ≥ 2 written so no d satisfies it), or a
  universally quantified d where only a specific d is proved.
