# Reference statement: the finite basis classification of the semigroups of order six

Written before opening any `.lean` file of the artifact, from the standard
definitions of universal algebra and semigroup varieties (Burris–Sankappanavar,
*A Course in Universal Algebra*, §II.14 (Birkhoff's completeness theorem);
Volkov, "The finite basis problem for finite semigroups", Sci. Math. Jpn. 53
(2001); Lee–Zhang, "Finite basis problem for semigroups of order six", LMS J.
Comput. Math. 18 (2015); Lee–Li–Zhang, "Minimal non-finitely based semigroups",
Semigroup Forum 85 (2012)). One clause per item so `STATEMENT.md` can pair
each with its Lean counterpart.

Disclosure: the artifact's `README.md` (sections The theorem, What a reader
has to trust, Are these the right tables?, Scope and limitations) was read
before this file was written, and that README QUOTES four Lean definitions
(`SatisfiedBy`, `BasisFor`, `FinitelyBased`, `Classified`) and paraphrases
`Derives`. So this reference is not blind to the README's rendering of them;
it is blind to the `.lean` files themselves. Every clause below is stated from
the textbook, and where the README's rendering differs from the textbook that
difference is a check item (W-list), not an assumption.

## Objects

- O1. **Alphabet.** A countably INFINITE set X of variables (x₁, x₂, …).
  Any infinite X gives the same notions; a finite X does not (W4).
- O2. **Words.** X⁺, the free SEMIGROUP on X: nonempty finite sequences of
  variables, multiplication = concatenation. No empty word (the empty word
  belongs to monoid identities, a different theory: x ≈ 1-type identities
  would then need an identity element to evaluate).
- O3. **Semigroup.** A set S with a binary operation · that is ASSOCIATIVE.
  For S of order six, S may be taken on the carrier {0,…,5}, the operation
  given by a 6×6 table t with t[i][j] = i·j, entries in {0,…,5}.
- O4. **Evaluation.** A valuation is an arbitrary map φ : X → S. It extends
  uniquely to a homomorphism φ̂ : X⁺ → S, φ̂(x_{i1}⋯x_{ik}) =
  φ(x_{i1})·…·φ(x_{ik}); well defined (bracket-independent) only because ·
  is associative.
- O5. **Identity.** An ordered pair (u, v) ∈ X⁺ × X⁺, written u ≈ v.
- O6. **Satisfaction.** S ⊨ u ≈ v iff φ̂(u) = φ̂(v) for EVERY valuation
  φ : X → S. Id(S) = { u ≈ v : S ⊨ u ≈ v } (the equational theory).
  Id(S) is closed under the rules of O7, i.e. is a fully invariant
  congruence on X⁺.
- O7. **Derivability (equational logic for semigroups).** For a set Σ of
  identities, Σ ⊢ u ≈ v is the least relation on X⁺ containing:
  - (Ax) every u ≈ v ∈ Σ;
  - (Refl) u ≈ u for every word u;
  - (Sym) from u ≈ v infer v ≈ u;
  - (Trans) from u ≈ v and v ≈ w infer u ≈ w;
  - (Subst) from u ≈ v infer θ(u) ≈ θ(v) for every substitution θ, i.e.
    every endomorphism of X⁺, i.e. every map X → X⁺ (words, not only
    variables, and simultaneous on all variables);
  - (Compat) from u ≈ v infer wu ≈ wv and uw ≈ vw for every word w
    (multiplication on BOTH sides; equivalently from u≈v, u'≈v' infer
    uu' ≈ vv').
  Equivalent standard forms: (i) the fully invariant congruence generated by
  Σ; (ii) one-step rewriting: u → v when u = p·θ(s)·q, v = p·θ(t)·q with
  (s ≈ t) ∈ Σ ∪ Σ⁻¹, p, q possibly empty, closed reflexively and
  transitively. Single-variable substitution x ↦ w iterated is equivalent to
  simultaneous substitution GIVEN an infinite alphabet (rename through fresh
  variables); with a finite alphabet it is not obviously equivalent.
  Birkhoff: Σ ⊢ u ≈ v iff every semigroup satisfying Σ satisfies u ≈ v.
- O8. **Basis.** Σ is a basis (identity basis) of S iff Σ ⊆ Id(S) AND every
  identity of Id(S) is derivable from Σ (Σ ⊢ e for all e ∈ Id(S)).
  Equivalently: the variety defined by Σ is the variety generated by S.
- O9. **Finitely based.** S is finitely based (FB) iff it has a FINITE
  basis. Nonfinitely based (NFB) iff it is not FB. Over an infinite
  alphabet; for a finite S this is a nontrivial property (every finite
  semigroup of order ≤ 5 is FB — Trahtman / Lee–Li–Zhang; order six is the
  smallest order with NFB examples, B₂¹ of Perkins 1969 being the classic).
- O10. **Invariance.** If S ≅ T then Id(S) = Id(T) (a valuation into S
  composed with the isomorphism is one into T), so FB is iso-invariant. If
  S is anti-isomorphic to T, i.e. T ≅ S^op (a·_op b = b·a), then
  Id(S^op) = { ū ≈ v̄ : u ≈ v ∈ Id(S) } where ū is u reversed; reversal is
  an anti-automorphism of X⁺ that maps each rule of O7 to a rule of O7
  (Compat-left ↔ Compat-right, Subst commutes with reversal up to reversing
  the substituted words), so Σ̄ is a basis of S^op iff Σ is a basis of S.
  Hence FB is invariant under anti-isomorphism, and a 6×6 table and its
  TRANSPOSE (which is the table of the opposite semigroup) have the same FB
  status.

## The catalogue

- K1. The semigroups of order six up to isomorphism AND anti-isomorphism
  number 15,973 (OEIS A001423: 1, 4, 18, 126, 1160, 15973, 836021, …;
  orders 1–5 sum to 1,309). GAP Smallsemi enumerates them as
  `SmallSemigroup(6, k)`, k = 1 … 15973, one representative per class.
- K2. The four NFB classes (Lee–Li–Zhang 2012; Lee–Zhang 2015): the
  semigroups the literature calls L, B₂¹ (Brandt monoid: the 5-element
  Brandt semigroup B₂ with an identity adjoined), A₂ᵍ and A₂¹ (A₂ with an
  identity adjoined). Their Smallsemi ids are claimed to be 3843, 8564,
  8878, 13747. I cannot regenerate Smallsemi here (no GAP), so these ids are
  checkable only against the repository's own records and the published
  tables; the reference fixes the NAMES, not the ids.

## Hypotheses

- H1. None beyond "e is a listed table". The claim is a finite conjunction
  over the catalogue.

## Conclusion

- C1. For every k ∈ {1,…,15973}: let S_k be the semigroup of
  `SmallSemigroup(6, k)`. If k ∈ {3843, 8564, 8878, 13747} then S_k is NFB;
  otherwise S_k is FB.
- C2. (Implicit in C1) each listed table IS the table of a semigroup
  (associative), so S_k exists.
- C3. NOT part of the claim as a theorem about tables, but part of the
  informal headline "every semigroup of order six": completeness of the list
  (every semigroup of order six is isomorphic or anti-isomorphic to some S_k).
  Given K1 and O10, C1 + completeness ⇒ every semigroup of order six is FB
  except those isomorphic or anti-isomorphic to the four.

## What would make a formal version weaker, vacuous or different

Direction convention: "FB claim" = the 15,969 positive claims, "NFB claim" =
the four negative ones.

- W1. **`Derives` missing a rule** (no Subst, Subst by variables only,
  Compat on one side only, no Sym, …). Fewer derivations ⇒ "Σ is a basis" is
  HARDER ⇒ a formal FB claim is STRONGER than the textbook one (still
  sound: a basis under a sub-calculus is a basis under the full one), but a
  formal NFB claim is WEAKER, possibly vacuous: e.g. without Subst no finite
  Σ derives the infinitely many instances x^n ≈ … of a single law, so every
  infinite Id(S) — every nontrivial S — would be "NFB". So for the NFB half
  the calculus must be AT LEAST the full O7.
- W2. **`Derives` with an extra or too strong rule** (e.g. a rule deriving
  every pair, cancellation, a rule u≈v ⊢ u ≈ v' with v' arbitrary, axioms
  not restricted to Σ, or Ax admitting identities of S rather than of Σ).
  More derivations ⇒ FB EASIER, possibly trivial (if Σ = ∅ derives
  everything, every S is FB) ⇒ the FB claim is WEAKER/vacuous; the NFB claim
  becomes stronger (likely unprovable, so a proof of it is no worry). So for
  the FB half the calculus must be AT MOST O7 (sound: Σ ⊢ e ⇒ every model of
  Σ satisfies e).
- W3. **`BasisFor` without "Σ ⊆ Id(S)"**: then Σ = {x ≈ y} is a basis of
  everything ⇒ FB vacuous. Or with only "Id(S) ⊆ Th(Σ)" quantified over a
  restricted set of identities ⇒ FB weaker.
- W4. **Alphabet finite or too small.** Over a finite alphabet of n letters,
  Id_n(S) of a FINITE S is always finitely based within n-letter derivations
  (the n-generated free algebra of the variety of S is finite, so finitely
  many relations present it), so "FB over Fin n" would be vacuous for every
  finite S and "NFB over Fin n" false/unprovable. FB must be over an
  infinite alphabet (ℕ). "FinitelyBasedOver α" for α other than ℕ is
  irrelevant to the claim only if the headline fixes α = ℕ for BOTH halves.
- W5. **`SatisfiedBy` over too few valuations** (e.g. only injective ones,
  only valuations into a fixed subset, or with an existential): satisfaction
  becomes weaker, the formal Id(S) BIGGER; a basis must then derive MORE
  (FB harder) but its members need only hold in the weak sense (FB
  possibly easier) — the effect is not monotone, so any such deviation is a
  DIFFERENT statement. Must be ∀ φ : X → S, all maps.
- W6. **`Semigroup` without associativity**, or evaluation fixing a
  bracketing (e.g. a left fold over a list) without associativity: then
  "a semigroup with this table" includes non-associative magmas and the
  object is a different one; and C2 (the table is a semigroup) is not
  checked. Must carry an associativity proof (or have it implied by
  `HasTable` + a checked table).
- W7. **Table encoding.** If `HasTable G rows` reads entries through a
  default (`getD`, `get!` with a default, `Fin` wraparound `% 6`), then a
  malformed `rows` (wrong length, short rows, entries ≥ 6) still determines
  SOME operation, and "∃ G with HasTable G rows" proves that the PADDED or
  WRAPPED table is a semigroup, not the listed one. Then the theorem is about
  a different table than the data appears to show. Checked by: the rows are
  well-formed (6 rows of 6 entries in 0..5) — ideally in Lean, else by a
  script.
- W8. **`Classified` quantifier structure.** "Some semigroup with this
  table is FB" (∃) vs "every semigroup with this table is FB" (∀). If a
  semigroup is exactly an operation plus a proof of associativity, all
  semigroups with a given table are equal (funext + proof irrelevance) and ∃
  and ∀ agree given existence; if the structure carries other data, ∀ is
  required. A ∀ alone is vacuous when no G has the table (unsatisfiable
  `HasTable`), so the existence conjunct (C2) is load-bearing.
- W9. **Wrong catalogue.** Count ≠ 15,973; ids not 1..15973 in order;
  duplicated tables (coverage loss without falsity); tables not those of
  Smallsemi (anything other than an isomorphic or anti-isomorphic copy of
  the same class changes the theorem's object); row/column convention
  swapped — HARMLESS for the truth of C1 by O10 (transpose = opposite
  semigroup, same FB status), but must be stated; element relabelling
  (1..6 → 0..5, or any permutation) — harmless by iso-invariance.
- W10. **Wrong exceptional ids.** If `nonfinitelyBasedIds` named a
  different set, the theorem would assert FB of an NFB semigroup — which
  would be FALSE, so a kernel-checked proof of it would point at W1–W8, not
  just at a typo. The set membership test must be on the same id field the
  catalogue lists.
- W11. **NFB defined as something other than ¬FB over the SAME alphabet
  and calculus** (e.g. "no basis with ≤ n variables" for a fixed n, or
  ¬FB over a finite alphabet, which is false for finite S by W4).
- W12. **Headline ≠ classification** (e.g. the headline theorem quantifying
  over a different list than the one `order6_length`/`order6_ids` describe,
  or the two corollaries not implied by/implying the main theorem).
